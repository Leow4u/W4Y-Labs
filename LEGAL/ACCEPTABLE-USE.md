# Acceptable Use Policy — Work4You

Last updated: 2026-08-06

Use of Work4You (web, desktop, cloud runtime, and terminal) must comply with
this policy. Violations may result in account suspension and key revocation.

## Prohibited

- Attempting to access another tenant's data or sessions
- Automated mass account creation, credential stuffing, or bypassing rate limits
- Reselling or redistributing platform-managed API access without authorization
- Running unsolicited bulk messaging, spam, or harassment via connected channels
- Mining cryptocurrency or unrelated high-load workloads on shared infrastructure
- Probing or attacking Work4You systems without written authorization
- Uploading or executing malware, or using the agent to attack third parties

## Free tier

The Grátis plan includes a limited allowance. Creating multiple accounts to
circumvent limits is prohibited.

## Agent execution

You are responsible for commands the agent runs on your machine or tenant.
Use approval prompts unless you trust the full context of a session.

## Enforcement

W4Y Labs may suspend tenants, revoke API keys, and block IPs without notice
when abuse is detected.

Contact: abuse@work4you.ai
